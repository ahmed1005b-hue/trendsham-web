# Quickstart: التحقق من نظام نقاط الولاء

دليل لإثبات أن الميزة تعمل من البداية للنهاية. التفاصيل في [data-model.md](data-model.md) و[contracts/](contracts/).

## المتطلبات

- نسخة احتياطية من القاعدة قبل الهجرات: `C:\xampp\mysql\bin\mysqldump -u root trendsham > backup.sql`
- `php artisan migrate` بعد موافقة صاحب المشروع.
- قاعدة الاختبار `trendsham_testing` موجودة.

## التحقق الآلي

```bash
php artisan test --filter=Loyalty      # اختبارات الميزة
php artisan test                       # المجموعة كاملة يجب أن تبقى ناجحة
cd C:\Users\istanbul\Desktop\trendsham_flutter && flutter analyze && flutter test
```

## التحقق اليدوي في المتصفح

1. سجّل كعميل، أكمل طلباً، ثم سلّمه من لوحة المدير → افتح `/customer/points`.
2. أضف منتجاً للسلة → تحقق من عبارة "ستكسب…" في صفحة المنتج والسلة والدفع.
3. في الدفع فعّل "استخدم نقاطي" → تحقق من سطر الخصم والمجموع.
4. حوّل نقاطاً لكوبون → افتح محفظة الكوبونات.
5. كرّر في الوضع الداكن وعلى عرض جوال.
6. في التطبيق: شاشة "نقاطي" من الملف الشخصي، ومفتاح النقاط في شاشة الدفع.
