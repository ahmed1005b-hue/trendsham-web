# تريندشام (TrendSham)

منصة تجارة إلكترونية متعددة البائعين — Laravel 12 / Bootstrap 5 / MySQL.

## التشغيل المحلي

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
npm install && npm run build
php artisan serve
```

مستخدم المدير الافتراضي بعد `migrate --seed`: الهاتف `0999999999` (دخول عبر OTP، الرمز يظهر في `storage/logs/laravel.log` طالما `SMS_DRIVER=log`).

## تفضيلات الويب

تدعم واجهة الويب العربية والإنجليزية والتركية عبر الصفحات العامة وصفحات الحسابات ولوحات التحكم والواجهات المستقلة وتقارير PDF. استخدم محدد اللغة أعلى الصفحات؛ الاختيار محفوظ في الجلسة وملف تعريف ارتباط لمدة سنة، ويُقبل فقط `ar` و`en` و`tr`. تُعرض العربية من اليمين إلى اليسار، والإنجليزية والتركية من اليسار إلى اليمين. تحفظ ترجمات النصوص الثابتة في `lang/en.json` و`lang/tr.json`. يبقى محتوى المنتجات والمتاجر الذي يدخله المستخدم بلغته الأصلية.

يمكن تغيير المظهر من المحدد نفسه إلى فاتح أو داكن أو اتباع إعداد الجهاز. يُحفظ اختيار المظهر محلياً في المتصفح (`localStorage`) ولا يحتاج إلى حساب.

## الحالة الحالية (المرحلة الأولى)

- تسجيل/دخول بالهاتف عبر OTP
- لوحات منفصلة: مدير / بائع / عميل (بحماية role middleware)
- بنية جاهزة لربط بوابة SMS حقيقية (`config/sms.php`)
- واجهة الستوريات العامة لتطبيق Flutter: `GET /api/v1/stories` (تعيد الستوريات النشطة وغير المنتهية ضمن `data`)
- صفحة متجر عامة للبائع المعتمد على الويب عبر `/store/{sellerProfile}` وواجهة بيانات المتجر ومنتجاته للتطبيق عبر `GET /api/v1/stores/{sellerProfile}`
- اقتراح منتجات مشابهة والأكثر مبيعاً عبر `GET /api/v1/products/{product}/recommendations`

## المراحل القادمة

الأقسام والمنتجات، السلة والطلبات، العمولات والمحفظة، التقييمات والإشعارات، تطبيق Flutter.
